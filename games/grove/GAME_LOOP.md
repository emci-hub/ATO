## Two moods, one loop

**Grove (chill — default open).** Tend the living base. Dress the Avatar. Claim Research. Decorate. Soft music. No fail state.

**Defend (spicy — optional).** 60–90s TD wave. Towers sit on the path. **Hero is movable** anywhere on the board (Kingdom Rush style) — skill ceiling is dragging them to the leak. Clear → bigger tokens.

You can live in Grove only and still earn. Defend is a boost, not the door.

## One session

1. Open into **Grove**. Claim Research (timer done offline). **Bag of finds**. Maybe +1 Dive charge.
2. Optional: **Dive** — live push-your-luck (see below).
3. Put one piece on Avatar **or** one decor in the Grove.
4. Optional: tap **Defend** → one wave → tokens + XP.
5. Or skip Defend → still get **tend tokens** for claim / dress / decorate.
6. Close. Research timer starts. Dive charges refill slowly.

Idle = volume. Dive = one better roll you watch. Defend = spicy. Grove holds all three.

## Roles

| Piece | Job |
|---|---|
| Avatar (Canopy Warden vibe) | Player. Fashion + commander. Looks = status. |
| Grove | Chill home. Decor, plants, soft light. Where gamer-chill players live. |
| Research | Offline earn. **Multiple finds** (not Defend scrap). Often grants +1 Dive charge. |
| Dive | Active. Spend 1 charge. Live go-deeper loop. Bank or risk. |
| Defend | Optional TD. Towers + avatar hero. |
| Dive charges | Soft cap ~10. Refill on a timer. Also earned from Research claims. |
| Tokens | Soft currency for the app. Tend = drip. Dive = small. Wave = burst. |
| Golden loot | Rare on Dive (and luck on Research). Visual piece or strong buff. |

## Tokens (app currency)

- Tend claim → tokens (always).
- **Daily tend bonus:** first Claim / Dress / Decor of the local day → +10 once (no streak punish).
- Clear a Defend wave → larger tokens + optional **share glow card**.
- Same token pool. One economy.

## Dive (interactive, still light)

Push-your-luck, not a depth menu. Manual = quality moment. Research = volume.

- Research claim → pile of scrap. Chance to mint a Dive charge.
- Spend 1 of ~10 charges to start a Dive.
- Charges refill over time. Never required for Grove. One Grove button. Not a swimming open world.

### Live dive

1. Splash → short delay → show **what you have now** (item + rarity).
2. Show the chance bar for **going deeper**: better upgrade odds + rising **bust** %.
3. Ask: **Surface** (bank this find) or **Deeper** (risk it for a better / extra find).
4. Deeper → delay → either upgrade / add to the haul, or **bust** (lose this dive’s haul, charge already spent).
5. Soft cap on how many Deepers per charge (e.g. 3–5) so one dive can’t run forever.

Fail = lose **this dive’s haul** only. Never strip equipped gear. Never wreck Grove.

Chill players Surface early. Spicy players push. Same screen.

### Show chances (always)

On every “keep going?” beat, print:

- Keep current: [item name]
- If deeper: upgrade to Rare xx% / Golden xx% / add second find xx%
- Bust xx% (climbs each Deeper)

No hidden math. Trust > mystery boxes.


## Items (Core + mult + mult)

Phone games that stay light use **base × separate multiplier buckets**, not 40 unique abilities. Maple-idle stacks many buckets; we keep **one Core + up to two mult lines**.

### Anatomy of one item

| Layer | What it is |
|---|---|
| **Core** | Slot + rarity + look (and a tiny base if Power). Identity. “Leaf Cape,” “Tide Blade.” |
| **Mult A** | One roll from the fixed span below. |
| **Mult B** | Optional second roll (Rare+). Same span, different knob preferred. |

**Look items** = Core only (art). Mult A/B empty. Chill progress.
**Power items** = Core + Mult A (+ Mult B if lucky Dive).

### Multiplier span (fixed forever)

1. Wave power  
2. Tower speed  
3. Token earn  
4. Dive luck  
5. Research yield  

New content = new Core art + different mult numbers. Never a new combat system.

### How math stays sane

- Same knob from two pieces **adds** inside its bucket (e.g. +8% and +5% wave → +13%).
- Different knobs **multiply** across buckets (wave × speed × tokens).
- Soft-cap each bucket (~×2). Chasing the empty knob beats stacking one forever.

Equip: 4 slots, one item each. Show on the card: Core name + Mult A + Mult B.

### Type tag (optional, later)

A light **type** on the Core (reuse Grove colors: Ink / Paper / Steel / Bloom) can give a small match bonus vs that week’s wave tint. Not day one. Not a full fire/ice/lightning tree — those explode design weight.

Dive can roll Look Cores or Power Cores with juicy Mult A/B — that’s how push-your-luck feeds winning waves.

## Soft infinite loop (phone-game standard)

The loop never “ends.” Time gates it.

| Action | Gate |
|---|---|
| Research claim | 30 min cycles; **fills offline to 10h then stops** until Claim |
| Dive charges | Soft cap ~10, refill 1 every ~10 min; Research can +1 |
| Defend waves | Free; skill ceiling is drag + towers (no energy gate v0) |
| Daily tend bonus | +10 tokens once/local day on first Claim / Dress / Decor |
| Tokens | Always earnable; big bursts = wave clear / lucky Dive |
| Share glow | Win Defend → optional ATO-style share card |
| Ads (later) | 1 rewarded/day: +1 Dive **or** 2× next Research claim |

Session forever: claim when ready → optional Dive (until charges empty) → dress → optional Defend → leave → come back when timers tick.

That’s how Archero / idle hybrids stay infinite without new content every day: **cooldowns + multipliers + next wave number**, not new game modes.

## Keep light

- One Grove screen + one Defend board.
- 3 tower types max. 4 gear slots. A small decor shelf (start with ~8 props).
- Numbers as K / M / B. Simple math.
- No forced wave. No energy gate on Grove. No 8 sweaty menus.
- Pixel / chunky 16-bit. Soft palette on Grove, hotter FX only on Defend.

## Why they return

- Short (chill): research waiting + one new look or plant.
- Short (spicy): beat the next wave stronger.
- Mid: fill a gear slot **or** finish a Grove corner.
- Long: Avatar + Grove look rare together (collection).
- Daily: something pretty waiting when they open — not only a DPS check.

## Progression defs (hammered)

Industry split (Kingdom Rush / idle TD): **in-wave currency** vs **meta currency**. Don’t merge them.

### Two wallets

| Wallet | Earned how | Spent on |
|---|---|---|
| **Scrap** (in-wave) | Enemies die during Defend | Place towers / **tower levels 1→3** this run |
| **Tokens** (meta) | Tend, Dive bank, wave **clear** bonus | Soft app currency; optional permanent tiny tower base bump; Dive refresh |

Scrap resets next Defend. Tokens persist.

### How you get stronger (mix)

1. **Items** (Research bag + Dive push-your-luck) → equip Avatar / Hero → mults forever.
2. **Hero level** (meta) → tiny wave_power from clears.
3. **Tower level** (in-wave, scrap) → this run only, cheap Bloons/KR feel.
4. **Wave number** → enemies use count + hp_mult + speed (Bloons math).

Difficulty skill = **move the Hero** to where the banner is thick. Towers are set-and-forget; Hero is the finger.

### Movable Hero

- Drag anywhere on the Defend board (not locked to a pad).
- Attacks nearest enemy in a radius.
- One Hero max. Avatar can be the same unit if no ally Hero unlocked (Avatar = movable commander).
- One active skill from closed kit (GAME_SPEC §9d); drag stays the main skill.

## Difficulty + heroes (hammered)

### Difficulty (Bloons math, not Bloons features)

Do **not** copy camo / lead / purple immunities. Too heavy for phone.

Per wave number only:
- **count** of enemies up
- **hp_mult** up
- slight **speed** up late

Same pink puff enemy. Later waves = fatter banner of more of them + bigger HP. Numbers on screen as K/M. Freeplay after a soft clear = same formula keeps climbing.

Player strength = gear mults + optional hero + small levels, not 12 tower upgrade paths.

Power loop: Dive/Research → items → equip; clear waves → tokens + tiny XP; spend tokens → tower level / Dive refresh. Roles defined in GAME_DATA.md. Engine: **Expo Play screen inside ATO** (locked). Not Godot/Unity for this product.

### Elements (thin, later)

Not a player “swap element” mini-game day one.

Wave can carry a **type_tint** (Ink / Paper / Steel / Bloom). Equipped Core `type_tag` match → small wave_power bonus. Miss = normal damage. No immunities. Fridge until the number-scaling loop is fun.
